## Gates

### 1. Routing goes through the appliance

From the sibling Debian distro (WSL2 distros share the network namespace):

```
$ ip route get 1.1.1.1
1.1.1.1 via 192.168.127.1 dev wsltap src 192.168.127.2 uid 1000

$ ip route | head -3
default via 192.168.127.1 dev wsltap
172.27.32.0/20 dev eth0 proto kernel scope link src 172.27.37.90
192.168.127.0/24 dev wsltap proto kernel scope link src 192.168.127.2
```

Default route and the probe target both resolve via `wsltap` (gvproxy gateway `192.168.127.1`); `eth0` retains only its link-scope WSL NAT subnet with no default route. PASS.

### 2. DNS + TLS + TCP through the bridge
